Spring Boot JWT returns 403 on valid token

Cause: Clock skew between issuing and validating services.
Solution: Added a 30s leeway to the JWT parser.

Jwts.parserBuilder().setAllowedClockSkewSeconds(30).build();
spring-bootjwtauth

Postgres unique constraint fails silently on upsert

Cause: Missing ON CONFLICT clause.
Solution: Used ON CONFLICT (email) DO UPDATE.

INSERT INTO users (...) ON CONFLICT (email) DO UPDATE SET ...
postgresqlbackend
